# Getting started

Run **Shannon** on your machine.

## 1. Setup

```bash
npm install
```

## 2. Build

```bash
npm run build
```

Output is under `out/`. Use `npm run preview` to try the packaged layout as supported by electron-vite.

## 3. Run

```bash
npm run dev
```

## 4. Requirements

- **Node.js** 18+ (recommended: current LTS)
- npm (or a compatible client)
