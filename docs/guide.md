# Guide

## What it is

An Electron desktop monitor board for developer activity, starting with GitHub and built to add more sources later.

## Stack

`Electron`, `React`, `TypeScript`

## Capabilities

### GitHub activity board

Track developer/org activity from GitHub.

### Desktop app

Electron + React + electron-vite.

### Token settings

PAT-based access with recommended scopes.

### Extensible sources

UI ready for more connectors later.
