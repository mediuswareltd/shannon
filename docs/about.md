# About Shannon

## Who maintains it

Shannon is built and maintained by [Mediusware](https://mediusware.com), a software company that designs and ships products for clients worldwide. The source lives at [github.com/mediuswareltd/shannon](https://github.com/mediuswareltd/shannon).

## Why it exists

An Electron desktop monitor board for developer activity, starting with GitHub and built to add more sources later.

We publish these tools so teams can evaluate the real software, not a slide deck: clone it, run it, and read how it is put together.

## Documentation

- Docs site: https://mediuswareltd.github.io/shannon/
- Getting started, guide, and about pages are generated from the project README and kept next to the code under `docs/`.
